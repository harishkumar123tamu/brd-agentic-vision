# BRD Agentic Vision

A computer vision system that tracks individual cattle, monitors their behavior, and looks for changes that could be early signs of bovine respiratory disease (BRD).

Built at the Merck TAMU Animal Science Hackathon 2026.

**Team:** Srikant, Harish, Suhas

## What it does

Tracking individual cattle in a group is difficult, especially when they look almost the same. Our dataset has ten black Angus cattle in Pen 6, recorded by three cameras over two days.

We wanted to give each cow an ID, track what it does during the day, and check for changes in feeding, drinking, lying, and movement.

We then compare each cow with the rest of the herd and give it a risk score. The score helps us decide which cow needs a closer look. It doesn't mean the cow has BRD.

## How it works

- **Cow Detection:** YOLO11m detects cattle in the videos. We remove duplicate boxes and detections outside the pen.
- **Individual Tracking:** The system tracks C01 to C10 using Camera 03 as the main reference. Cameras 01 and 02 help track cows near the feeding bunk.
- **Camera Zones:** We marked the pen, feeding bunk, and water areas to help with behavior tracking.
- **Behavior Monitoring:** We use tracking and camera zones to estimate feeding, drinking, lying, walking, and other activities. Rumination and some smaller behaviors still need more checking.
- **BRD Risk Scoring:** We compare each cow's activity with the herd and with its activity from the previous day when possible.
- **Dashboard:** The Streamlit dashboard shows cow rankings, risk scores, and behavior information.

Harish's detection, tracking, and agent pipeline details are in `PIPELINE.md`.

## Run it yourself

### 1. Clone the repository

```powershell
git clone https://github.com/harishkumar123tamu/brd-agentic-vision.git
cd brd-agentic-vision
```

### 2. Install dependencies

```powershell
py -3.12 -m pip install pandas numpy opencv-python pyarrow streamlit plotly
```

FFmpeg is also needed for video processing. Some of our video files need the correct video stream selected when decoding.

### 3. Run the real-data risk scoring

```powershell
py -3.12 level2/build_risk_real.py --activity outputs/activity.csv --source real
```

This uses the activity data generated by our video pipeline and saves the risk scores in `level2/`.

There is also `level2/build_risk.py` for testing with simulated data. Those test scores should not be confused with the real-data results.

### 4. Open the dashboard

```powershell
py -3.12 -m streamlit run dashboard/app_srikant.py
```

Open the local URL shown in the terminal.

The detection and tracking scripts are in `pipeline/`. See `PIPELINE.md` for more on the cluster pipeline.

## BRD Risk Scoring

We look at changes in activity because a cow feeding less or lying more than usual may need attention. But every cow behaves differently, so we compare each one with the herd and with its own previous day.

Our original scoring plan used these weights:

- Feeding duration: 30%
- Feeding visits: 15%
- Lying duration: 20%
- Rumination: 15%
- Isolation: 10%
- Change between days: 10%

The real-data run couldn't include rumination or isolation because those measurements weren't available. The code in `level2/build_risk_real.py` is the source for how the final scores were calculated, so the weights above shouldn't be treated as the exact final formula.

The score is between 0 and 1. It is only a relative ranking to help us decide which cows to check, not a BRD diagnosis or disease probability.

## Results so far

We now have **6,007 video-derived activity records** for **10 cows across two days**, saved in `outputs/activity.csv`.

The top three cows from the real-data scoring run are:

| Rank | Cow | Risk score |
|---|---|---|
| 1 | C02 | 0.6619 |
| 2 | C03 | 0.6410 |
| 3 | C08 | 0.6101 |

The full results are in `level2/brd_risk.csv`, `level2/features.csv`, and `level2/risk_source.json`.

We also made three risk cards for C02, C03, and C08. Each card compares the cow's activity with the herd and includes video references. The nine clip references are listed in `docs/clips/index.csv`.

According to the team's November 14 update, the dataset had 1,749 clips (about 153 GB). The detection pipeline had processed around 264,000 keyframes. The team reported 99.1% tracking continuity on Camera 03 and cow ID coverage of around 92% and 93% at the feeding bunks on Cameras 01 and 02. These are pipeline results, not independently verified cow ID accuracy.

For ground truth, we labeled 60 frames with 367 cow boxes and marked pen zones for all three cameras. The cow ID sheet is started, but the IDs still need independent verification across both days.

**Validation is not finished yet.** We haven't completed the planned 200-300 cow-minutes of manual behavior labels, and we haven't fully verified all ten cow IDs. We also don't have veterinary-confirmed BRD outcomes. So we're not claiming measured behavior accuracy, cow ID accuracy, or disease prediction accuracy.

More details are in `docs/final_validation_status.md`.

## Challenges we ran into

- **Similar-looking cattle:** All ten cows are black Angus, so we had to rely a lot on position and movement to keep track of IDs.
- **Camera Visibility:** Cows block each other, leave the camera view, and are harder to see in nighttime recordings.
- **Video Processing:** Some videos had a nonstandard codec tag and needed extra FFmpeg settings.
- **Camera Calibration:** We couldn't clearly see every pen landmark from every camera.
- **Behavior Verification:** Feeding and lying are easier to estimate from videos than rumination or other small movements.
